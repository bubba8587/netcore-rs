## Decision

netcore-rs reimplements rete's headless graph model (the editor, its signal pipes, the classic preset) and rete-engine's dataflow engine in Rust, keeping upstream's behavior.

## Why

Solenoid's graph model and compute pass run on rete, and Solenoid is moving its core to Rust, so the graph layer under it should be Rust too.
